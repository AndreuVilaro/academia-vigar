2. Dades i informació tractades a través del web

El web no disposa de formularis de contacte, àrea d’usuari ni sistema de registre i, per tant, no demana directament dades personals mitjançant formularis.

Acadèmia Vigar utilitza Cloudflare Web Analytics per obtenir estadístiques agregades sobre l’ús i el rendiment del web. Segons la documentació de Cloudflare, aquest servei no utilitza cookies ni localStorage per recollir mètriques d’ús, no crea empremtes digitals dels visitants i no recull ni utilitza dades personals dels visitants amb aquesta finalitat.

Si decideixes contactar amb Acadèmia Vigar mitjançant WhatsApp, telèfon o correu electrònic, es tractaran les dades que facilitis voluntàriament per poder atendre la teva consulta i, si escau, gestionar la relació derivada dels serveis sol·licitats.

3. Finalitat i base jurídica

Les dades facilitades en una consulta s’utilitzaran per respondre-la, facilitar informació sobre els serveis i gestionar les comunicacions relacionades amb la petició de la persona interessada. La base jurídica dependrà del cas: l’aplicació de mesures precontractuals sol·licitades per la persona interessada, l’execució d’una relació contractual quan existeixi o el consentiment quan sigui la base adequada.

4. Conservació

Les dades facilitades en les comunicacions es conservaran durant el temps necessari per atendre la consulta o mantenir la relació corresponent i, posteriorment, durant els terminis exigibles per complir obligacions legals o atendre possibles responsabilitats.

5. Destinataris i serveis de tercers

No es preveu comunicar dades personals a tercers, excepte quan sigui necessari per complir una obligació legal o per prestar un servei mitjançant proveïdors que actuïn conforme a la normativa aplicable.

El web utilitza Cloudflare Web Analytics en els termes indicats anteriorment. També inclou enllaços a serveis externs com WhatsApp. Google Maps només es carrega quan la persona usuària prem expressament el botó «Carregar mapa»; a partir d’aquell moment, Google tracta la informació corresponent d’acord amb les seves pròpies polítiques.

6. Drets

Pots exercir els drets d’accés, rectificació, supressió, oposició, limitació i portabilitat quan correspongui, escrivint a academia.vigar@gmail.com i indicant quin dret vols exercir. També pots presentar una reclamació davant l’Agència Espanyola de Protecció de Dades si consideres que el tractament no s’ajusta a la normativa.

7. Canvis en aquesta política

Aquesta política s’actualitzarà si canvien els serveis del web o la manera en què es tracten dades o s’utilitzen serveis de tercers.
